# KietMiniMart - He thong quan ly ban le

Du an WinForms + ASP.NET Core API + Entity Framework Core.

- Thuong hieu giao dien: KietMiniMart.
- Du lieu mau da chuyen sang cac mat hang cua hang tien loi/tap hoa: nuoc uong, mi goi, banh keo, sua, gia vi, hang gia dung, cham soc ca nhan va do dong hop.
- Cac gia va so luong la du lieu mau phuc vu bai tap.

## Luu y khi chay
Neu database cu da duoc tao va migration da ap dung, cac thay doi trong file seed khong tu dong thay doi du lieu cu. De xem du lieu mau moi, hay tao database moi/ xoa database bai tap cu roi chay lai migration. Sao luu database truoc khi xoa.
